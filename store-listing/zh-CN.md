# Chrome 网上应用店文案 — 简体中文

## 产品名称

轻译

## 简短说明

使用 Chrome 内置能力，在本地翻译网页中选中或鼠标捕捉的文字。

## 详细说明

阅读网页时不必频繁切换页面。轻译会在正在阅读的文字附近展示简洁的翻译结果，并通过 Chrome 内置语言能力在设备本地完成处理。

你可以根据习惯切换交互模式：

- 选中文字后立即翻译。
- 使用“鼠标捕捉”，悬停文字 500 毫秒后翻译。
- 随时在插件弹窗中切换目标语言。
- 在结果卡中复制、朗读、固定或关闭翻译。

轻译无需账号或 API Key，不使用开发者翻译服务器、数据分析、广告或远程代码。网页文字通过 Chrome 内置 API 处理，不会上传给开发者。

需要 Chrome 138 或更高版本。首次翻译某种语言时，Chrome 可能需要你的确认，以下载并准备对应的本地语言模型。

首个版本支持普通 HTTP 和 HTTPS 网页的顶层页面。Chrome 内部页面、Chrome 网上应用店页面、内置 PDF 阅读器和跨域框架暂不支持。
