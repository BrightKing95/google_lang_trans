# Chrome Web Store Listing — English

## Product name

Quick Translate

## Summary

Translate selected or hovered webpage text locally with Chrome's built-in translation.

## Detailed description

Read webpages without interrupting your flow. Quick Translate shows a compact translation beside the text you are reading and uses Chrome's built-in language capabilities on your device.

Choose the interaction that suits you:

- Select text to translate it immediately.
- Use Mouse capture to translate a text block after hovering for 500 milliseconds.
- Switch the target language at any time from the extension popup.
- Copy, listen to, pin, or close a translation from the result card.

Quick Translate requires no account or API key. It does not use a developer-operated translation server, analytics, advertising, or remote code. Page text is processed through Chrome's built-in APIs and is not uploaded to the developer.

Requires Chrome 138 or later. The first translation for a language may require your confirmation while Chrome downloads and prepares its language model.

The first release works on ordinary top-level HTTP and HTTPS webpages. Chrome internal pages, Chrome Web Store pages, the built-in PDF viewer, and cross-origin frames are not supported.
