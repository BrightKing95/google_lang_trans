# 轻译弹窗视觉优化设计

## 背景

当前弹窗功能完整，但信息层级较平、控件接近浏览器默认样式、品牌辨识度不足。此次改版仅优化弹窗结构与视觉，不改变翻译引擎、网页浮层、权限、存储格式或现有交互语义。

## 已确认方向

- 视觉风格：柔和品牌。
- 主色：天空蓝，以蓝色到靛蓝的轻渐变形成品牌识别。
- 弹窗宽度：336px。
- 同时支持系统浅色和深色模式。
- 允许轻微调整 HTML 结构，加入模式图标、辅助说明与隐私提示。
- 保持安装后无需配置、界面跟随 Chrome UI 语言的产品原则。

## 信息架构

弹窗自上而下分为四个区域：

1. 品牌与开关：品牌图标、扩展名称、简短副标题和启用开关。
2. 能力状态：紧凑状态胶囊，显示就绪、准备中、不可用或错误状态。
3. 核心设置：翻译模式卡片和目标语言下拉框。
4. 隐私提示：说明翻译由 Chrome 本地能力完成，网页内容不会上传。

顶部使用柔和渐变背景，设置区保持浅色实体表面，避免整页渐变造成视觉噪音。主要交互仍集中在模式与目标语言，不新增设置项。

## 组件设计

### 品牌区

- 使用带“译”字的圆角渐变图标，不引入远程图片或字体。
- 扩展名称下增加本地化副标题。
- 启用控件继续使用原生 checkbox，由 CSS 绘制为开关外观。
- checkbox 必须保留可聚焦、可键盘操作和可被屏幕阅读器识别的语义。

### 状态胶囊

- 复用现有 `#status` 和 `data-state` 状态模型。
- 就绪状态使用绿色圆点；准备状态使用琥珀色；不可用和保存错误使用红色。
- 错误只改变状态区域，不改变现有失败回退逻辑。

### 模式卡片

- 继续使用 `fieldset`、`legend` 和同名 radio，维持互斥与可访问语义。
- 每张卡片包含装饰图标、模式名称和一行本地化说明。
- 选中态使用天空蓝描边、淡蓝背景和轻阴影；未选中态保持白色或深色实体表面。
- radio 可视觉隐藏，但不可使用 `display: none`，焦点样式必须显示在整张卡片上。

### 目标语言

- 继续使用原生 select，保持键盘、搜索和系统语言列表能力。
- 外观改为 44px 高圆角输入框，增加装饰性语言图标。
- 不改变支持语言集合、显示名称生成或持久化逻辑。

### 隐私提示

- 在设置区底部加入一条本地化提示：“Chrome 本地翻译 · 网页内容不会上传”。
- 提示为说明文本，不增加链接或按钮。

## 本地化

新增文案必须同时加入英文和简体中文目录，并加入类型化消息键列表：

- 品牌副标题。
- 选中文字模式说明。
- 鼠标捕捉模式说明。
- 本地翻译隐私提示。

英文长文案必须在 336px 宽度下保持完整显示；不得依赖截断隐藏关键含义。其他 Chrome UI 语言继续按扩展默认语言回退。

## 深色模式

使用 `prefers-color-scheme: dark` 自动切换，不增加手动主题设置。深色模式保留天空蓝品牌色，但降低渐变亮度，主体使用深蓝灰表面和清晰的边框层级。所有正文、辅助文字、焦点环和状态颜色需要满足清晰可读的对比度。

## 数据流与错误处理

`initializePopup` 的加载、能力检测、设置写入和监听流程保持不变。现有 DOM 标识 `#enabled`、`input[name="mode"]`、`#target-language` 和 `#status` 必须保留，因此业务代码原则上无需改动。

设置加载失败时继续禁用全部控件；内置能力不可用时继续仅禁用模式控件；保存失败时继续回退到最后确认设置。新样式通过 `data-state` 呈现这些状态，不引入新的状态机。

## 测试与验证

实现采用测试驱动方式：

1. 先扩展弹窗源码结构测试，验证新增文案节点、控件标签和原生输入语义。
2. 扩展本地化目录一致性测试，确保新增消息键在英文和简体中文中均存在。
3. 保留并运行设置加载、模式互斥、目标语言持久化、能力不可用和失败回退测试。
4. 运行完整 `npm run validate`，覆盖类型检查、全部测试、生产构建和 dist 安全校验。
5. 分别以英文和简体中文检查弹窗，不得出现横向滚动、文字遮挡或控件跳动。
6. 分别检查浅色和深色模式截图，与确认的视觉稿核对。

## 验收标准

- 弹窗视觉与已确认的“柔和品牌 × 天空蓝”稿一致。
- 弹窗宽度为 336px，正常内容无需滚动即可完整使用。
- 启用、模式和目标语言设置的行为与改版前一致。
- 键盘焦点、表单标签和屏幕阅读器语义完整。
- 中英文界面及系统深色模式均无溢出或明显布局问题。
- 不增加远程资源、网络请求、权限或翻译内容存储。
- 完整验证通过后才可交付。
